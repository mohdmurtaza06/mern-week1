# MERN Stack - Week 1 Frontend Fundamentals

This project covers the Skill Nexis Week 1 requirements:

## Main assignments
1. Responsive personal portfolio using HTML + CSS
2. Five reusable React components: Header, Footer, Card, Button, Form
3. React Blog UI with JSON data, search, and category filtering

## Practice set
- Responsive navigation bar
- JavaScript form validation
- E-commerce landing page
- Flexbox/Grid layouts

## Run the React project

```bash
cd react-blog
npm install
npm run dev
```

Open the local URL shown by Vite.

## Portfolio

Open `portfolio/index.html` directly in a browser, or serve the folder with VS Code Live Server.

## GitHub submission

Create a repository named something like `mern-week1-frontend`, upload this project, and submit the GitHub repository URL in Skill Nexis.
